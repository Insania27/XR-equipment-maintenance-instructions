# Проверка прототипа

## Сценарии ПК

| Сценарий | Ожидаемый результат |
| --- | --- |
| Запуск без выбранной модели | Показ первого шага, переход блокируется |
| Выбор модели | Изменяется название и соответствующие тексты |
| Далее без подтверждения | Шаг не меняется |
| Подтверждение и Далее | Следующий шаг, новая стрелка, запись результата |
| Скрыть имитируемый маркер | Геометрия исчезает, Далее недоступно |
| Показать маркер снова | Текущий шаг восстановлен, нужно повторное подтверждение |
| Назад и повторное прохождение | Шаг возвращается; повторная запись не дублирует выполнение |
| Подтверждение последнего шага | Завершение и запись результата |
| Сначала во время прохождения | Первый шаг; прежний сеанс остаётся незавершённым |
| Изменение модели после первого шага | Заблокировано до сброса |

## Сценарии настоящего Android

Эти сценарии пока не выполнены; результаты нельзя выдавать за проверку на устройстве.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Первый запуск | Разрешение камеры, запуск ARCore без ошибок |
| Показ распечатанного маркера 12 см | Распознавание эталона и оценка положения |
| Постороннее изображение | Инструкция не активируется |
| Потеря Tracking | Пространственные подсказки скрываются, переход блокируется |
| До калибровки координат | Текст доступен, реальные стрелки скрыты |
| Калиброванная первая сторона | Стрелки совпадают с проверенными деталями |
| Перемещение корпуса на другую сторону | Прежние подсказки отключены |
| Подтверждение всех шагов | Java-мост работает, SQLite содержит один завершённый сеанс |
| Повторное подтверждение шага | Одна запись на номер шага в рамках сеанса |
| Перезапуск приложения | Сохранённые сеансы остаются в базе |
| Отказ в разрешении камеры | Можно перейти в режим ПК; ложное распознавание не появляется |

Перед защитой записать модель телефона, Android, CFI-номер PS5, условия освещения и фактические результаты.
