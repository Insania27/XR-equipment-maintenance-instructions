# Проверки 7 октября 2026 года

Выполнено:

- Файл инструкции читается как JSON; 10 шагов имеют уникальные идентификаторы.
- Исходный C# класс MaintenanceSession скомпилирован и проверен независимо от Unity.
  Проверены блокировка без подтверждения, отсутствие трекинга, неизвестная модель,
  возврат к шагу, полное прохождение и запрет изменения завершённого сеанса.
- SessionRules.java скомпилирован javac 20.0.2 и проверен на допустимые и недопустимые номера шагов.
- Все четыре Java-файла скомпилированы с официальным android.jar API 26, целевой уровень Java 8.
  Ошибок компиляции нет. Предупреждения javac о старом уровне Java 8 относятся к используемому компилятору 20.
- arcoreimg из официального ARCore XR Plugin 6.3.5 дал маркеру оценку 100/100.
- Архивы Unity-пакетов скачаны из официального реестра; SHA-1 сверены с метаданными реестра.
- При первом открытии выявлена компиляция внутренних тестов встроенных пакетов без NUnit.
  В 26 тестовых asmdef добавлено ограничение PS5_XR_RUN_VENDOR_TESTS; эта опция не включена.
  Код приложения и проверки MaintenanceSession этим ограничением не затрагиваются.
- Основной код приложения скомпилирован Unity после исключения тестовых сборок пакетов.
- Генератор сцены исправлен для API 6000.3.8f1 и повторно скомпилирован штатным Roslyn
  с теми же ссылками, которые использует Unity; ошибок компиляции нет.
- Unity 6000.3.8f1 успешно скомпилировала проект в отдельной проверочной копии,
  создала сцену и выполнила встроенные проверки логики.
- Собрана версия Windows. При запуске устранено отсутствие шейдера из-за удаления
  неиспользуемых ресурсов сборщиком: материал теперь явно хранится в Resources.
- В работающей сборке проверены подтверждение, потеря имитируемого маркера, возврат,
  прохождение всех шагов и сохранение результата в JSON. Проверка закончилась кодом 0.
- Интерфейс отрисован в собственную RenderTexture приложения и проверен визуально:
  русские надписи читаемы, кнопки и текст не перекрываются, схема и стрелка видны.
- После жалобы на качество в сохранённой раскладке Game View обнаружены включённый
  Low Resolution Aspect Ratios и масштаб 150%. Команда отключения низкого разрешения
  проверена в Unity и завершилась PS5_XR_GAME_QUALITY_CHECK_PASSED.
- Текст переведён на TextMeshPro с подготовленным SDF-шрифтом PT Sans и кириллицей.
  Повторно проверена отрисовка при 840 × 783 и 1100 × 1500; повреждённых глифов нет.
- Добавлены экран поиска изображения и пространственный контур маркера.
  Проверка UI поиска подтверждает блокировку действий до распознавания;
  это проверка интерфейса на Windows, а не проверка настоящего сканирования.
- По исходникам AR Foundation исправлена привязка камеры к HandheldARInputDevice
  и отключён искусственный сдвиг Camera Y Offset. Выбран Input System с подходящим UI-модулем.

Пока не подтверждено:

- Запуск APK на физическом Android: сборка создана и проверена, проверка на телефоне ещё не выполнена.
- JNI, SQLite и трекинг на настоящем Android: устройство ещё не выбрано.
- Совпадение стрелок с настоящей PS5: не получены CFI-номер, фотографии и расположение маркера.

Независимая компиляция Java не проверяет вызовы JNI и работу базы на Android.
Оценка качества маркера не доказывает устойчивость трекинга на выбранном телефоне.
Автоматическая проверка интерфейса не имитирует нажатия мышью: она вызывает методы
контроллера. Кнопки дополнительно проверяются вручную в Play Mode.

Дополнительно после сообщения о неработающих кнопках выполнен отдельный тест pointer-событий:
виртуальное устройство Mouse отправляет состояние через Input System, GraphicRaycaster
и InputSystemUIInputModule. Проверены «Модель», подтверждение, Далее и Назад;
методы onClick напрямую не вызываются. Получен PS5_XR_POINTER_CLICKS_PASSED, код завершения 0.
Для скрытого тестового окна разрешён ввод без фокуса; эта настройка применяется только в режиме теста.
В UI явно назначаются стандартные actions и отключаются старые модули EventSystem.
В журнале подтверждено, что открытый редактор продолжал работать прежним процессом
с момента до смены Active Input Handling; требуется его полный перезапуск.
